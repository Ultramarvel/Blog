# 林间信号 · Field Notes

一个无构建步骤的静态博客视觉原型。直接用浏览器打开 `index.html` 即可查看首页；首页首篇文章链接到 `posts/attention.html`。

## 页面

- `index.html`：首页、文章列表、作者介绍
- `posts/attention.html`：沉浸式文章页
- `styles.css` / `article.css`：响应式视觉样式
- `script.js` / `article.js`：主题切换、入场动效、阅读进度与目录高亮

页面字体从 Google Fonts 加载；离线时会自动使用系统字体回退。示例文章和作者信息目前是原型占位内容。
