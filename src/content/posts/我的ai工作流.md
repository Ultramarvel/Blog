我平时使用 AI 辅助开发，基本会按照五个步骤来做。
## 1. 环境搭建
先初始化 Git 仓库，方便记录每个功能的改动，出现问题时也能回退；同时在 AGENTS.md 中写清楚项目背景、代码规范和验证要求，让编程 Agent 每次开始工作时都能理解项目。、

## 2. 产品设计
我会先和 AI 讨论需求，明确这一版必须做什么、暂时不做什么，把范围收敛到能跑通核心流程的版本，再整理成简短的产品文档。如果界面交互比较复杂，我会先让 AI 做一个可操作的 Demo，实际体验后再调整设计。

## 3. 技术设计
基于确认的需求，让 AI 分析技术栈、模块划分和实现方案，我会重点检查它是否适合当前项目、复杂度是否合理，再把确定的方案作为开发依据。
## 4. 产品实现
让 Claude Code 或 Codex 这类 Agent 按文档分步骤写代码，同时给它运行项目、执行测试以及必要时操作页面的能力，让它先自行发现并修复明显的问题，而不是生成代码后就直接结束。
## 5. 人工验证
我会亲自运行功能，检查核心流程、有没有异常情况，实际使用体验如何；如果结果与预期有偏差，就把具体问题反馈给 AI，继续修改和验证。实际使用时，这套流程也会根据任务调整：简单需求可以快速实现并验证，复杂或重要的需求则需要更仔细地参与产品和技术设计。
我认为 AI 能明显提高开发效率，但需求判断、方案取舍和最终质量仍然需要我自己把关。
